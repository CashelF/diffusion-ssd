\begin{abstract}
\normalfont
Autoregressive (AR) decoding bottlenecks large language model (LLM) inference: each token requires a sequential forward pass through the target model. Speculative decoding (SD) accelerates this by using a small AR draft model to propose tokens that the target verifies in parallel, and Speculative$^2$ Decoding (S$^2$D) further removes idle time by having the draft model anticipate verification outcomes and pre-generate continuations. Both approaches, however, still draft tokens \emph{one at a time}. We replace the AR draft with a \emph{discrete diffusion} language model that fills an entire block of $k$ tokens in a small constant number of parallel refinement steps, and integrate it with S$^2$D so that draft generation, draft verification, and lookahead speculation overlap. We implement two diffusion drafters: a masked diffusion language model (MDLM) with mask-predict / remask samplers and full attention, and a block-diffusion model (BD3LM) with staircase attention, prefix-cache reuse, and a first-hitting sampler. We also add a switching scheme that warm-starts with an AR drafter before handing off to diffusion. We benchmark against AR, sync SD, and async S$^2$D baselines on HumanEval, Alpaca, GSM8K, and UltraFeedback. We report wall-clock throughput, target-step acceptance length, and qualitative samples to confirm that distributional fidelity is preserved.
\end{abstract}
